# FactorGuard 比赛演示脚本（3–5 分钟）

## 报名方向

选择 **金融行业 AI 应用开发（投研应用）**。FactorGuard 是面向量化投研工作流的完整应用，不是单独的金融投研 Skill。正式鉴证链由确定性引擎执行；可选大模型只作为证据约束下的投研辅助解读，调用不可用或输出不合规时自动规则降级。

## 演示前准备

如需现场演示真实模型调用，先在启动应用的同一 PowerShell 终端设置环境变量；不设置时会稳定展示规则降级：

```powershell
$env:FACTORGUARD_LLM_PROVIDER = "deepseek"
$env:FACTORGUARD_LLM_API_KEY = "<your-api-key>"
```

```powershell
py -m streamlit run app.py --server.headless true --server.port 8501
```

打开 `http://127.0.0.1:8501`。现场其他设备连接同一局域网时，使用演示电脑的局域网 IP 和端口 `8501`。

提前打开以下页面，避免现场临时寻找：首页、因子输入、鉴证运行、报告与凭证。正式 R001 全链路约 30–40 秒，可在等待时解释方法。

## 讲解主线

### 0:00–0:35 问题与定位

“普通回测回答因子过去赚没赚钱，但不回答结果是否用了未来数据、是否只依赖小微盘、是否只是旧因子改名。FactorGuard 是回测后的质量审计层，把每个结论拆成可检查、可反驳、可复现的证据。”

在首页指出正式比赛快照：2024-09-27 至 2025-09-26、1,314,224 行、5,473 只股票。

### 0:35–1:55 真实 R001 鉴证

1. 进入“因子输入”。
2. 快速选择 `R001 - 5日标准化收益动量`。
3. 进入“鉴证运行”，点击“开始鉴证”。
4. 等待时说明七步链路：输入检查、对齐、传统评估、压力测试、重复检测、证据生成、证据解释。
5. 结果重点：RankIC Mean 约 `-0.03264`，与 FactorSpec 的 `higher` 预期方向相反；即使数值显著，也不能判为支持。

核心话术：“系统不会因为一个漂亮指标就通过因子，方向、时点和关键压力证据必须同时成立。”

### 1:55–2:40 对抗式压力测试

进入“压力测试”，展示执行延迟、微盘剔除、市值中性化、极端样本四项结果。说明真实 R001 当前为 `warn/pass/pass/pass`，结论仍由统一证据引擎生成，而不是页面各自下结论。

可补充 Demo C：“同一个因子剔除小微盘后若明显衰减，说明收益可能来自规模暴露，而不是因子本身。”

### 2:40–3:20 失败案例与方法边界

- Demo A：未来函数检查失败，结论必须是“无效”。
- Demo D：资本效率代理可以真实计算，但数据缺少财务公告日期，因此时间正确性保持“未测试”，总体是“证据不足”。

核心话术：“能算出来不等于历史时点可用，系统会保留未测试状态，不把代理包装成已经验证的大师策略。”

### 3:20–4:10 报告与复现凭证

进入“报告与凭证”，展示证据维度、缺失项、`evidence_hash` 和 `report_hash`，再展示 HTML/Markdown/JSON 三种正式导出。

“同一份 FactorSpec、快照、参数和证据会得到确定性凭证；任何关键输入变化都会改变哈希，方便评审或研究团队复核。”

### 4:10–4:40 对应评分标准收尾

- 逻辑性：结论由统一证据规则生成，未测试不等于通过。
- 创新性：把回测结果升级为对抗式、可反驳的质量审计。
- 落地性：全市场真实快照、30–40 秒完成鉴证、可导出、可复现。
- 呈现方式：一条主流程、四个异常 Demo、统一结论与凭证。

## 现场备用方案

- 浏览器异常：重启 Streamlit，不需要重建 Parquet。
- 原始 CSV 不在演示电脑：不影响运行，正式提交包已包含 Parquet 快照。
- 时间不足：直接展示 `tests/artifacts/apptest_real_audit.json` 和报告页。
- 不要声称：当前演示一定调用了外部模型、已覆盖 2019–2026、财务公告时点已验证、所有内置因子均经过本次实时重算。应以 AI Tab 显示的 `model` 或 `rule_fallback` 来源为准。

## AI 辅助解读边界

报告页有独立的“AI 辅助解读”Tab，可选择 OpenAI、DeepSeek、通义千问、智谱、Moonshot、硅基流动或自定义兼容服务，并编辑模型 ID。API Key 只从环境变量读取，页面只显示是否配置。无模型配置时展示 `rule_fallback`；模型成功时展示 `model`、供应商、模型、`ai_analysis_hash` 和证据引用。演示时强调：它只能复述和质询已有证据，不能修改 RankIC、压力测试、重复性检测、证据状态或正式结论。

正式报告由确定性审计引擎生成；大模型只提供可引用、可校验、可降级的投研辅助解读，不参与正式裁决。
