# AI 辅助验真解读 - Proposal

状态：已批准实施  
变更标识：ai-auxiliary-analysis  
最后更新：2026-08-21

## 摘要

在不改变 FactorGuard 确定性计算、裁决和正式报告的前提下，增加可选的大模型辅助验真解读。模型只读取结构化证据摘要，输出带证据引用的反方质询和下一步实验建议；模型不可用或输出不合规时自动使用规则降级。

## 当前状态与问题

- 传统评估、压力测试、重复检测、证据裁决和三种正式导出均由确定性代码完成。
- `engine/ai_explainer.py` 当前是本地规则模板，没有外部模型调用。
- `report_hash` 当前包含 `ai_explanation`，导致辅助文本可能影响正式报告凭证，与产品可信边界冲突。
- 选择“金融行业 AI 应用开发（投研应用）”参赛时，需要真实、可审计的模型能力，但不能牺牲结论可复现性。

## 目标

- G-001：正式报告、结论与 `report_hash` 完全独立于模型输出。
- G-002：支持 OpenAI、DeepSeek、通义千问、智谱、Moonshot、硅基流动及自定义 OpenAI-compatible Chat Completions API，密钥仅来自环境变量。
- G-003：模型输出必须是结构化 JSON，并引用当前报告中真实存在的 `evidence_id`。
- G-004：模型缺失、超时、返回非法 JSON、虚构引用或试图改变结论时自动降级，核心流程继续可用。
- G-005：页面明确区分“正式鉴证报告”和“AI 辅助解读”，展示来源和免责声明。

## 非目标

- NG-001：不让模型计算 RankIC、压力指标或最终结论。
- NG-002：不让模型生成 HTML、Markdown 或 JSON 正式报告。
- NG-003：不发送原始行情、因子值明细、密钥或本地路径给模型。
- NG-004：不实现通用聊天、Agent 群或自动执行模型建议。

## 需求

| ID | 需求 | 优先级 |
| --- | --- | --- |
| REQ-AI-001 | `report_hash` 仅覆盖确定性正式报告载荷，不含任何 AI 文本。 | 必须 |
| REQ-AI-002 | AI 输入只包含因子标识、正式结论、五维评级和结构化证据记录。 | 必须 |
| REQ-AI-003 | 页面可选择受支持的供应商和模型 ID；自定义供应商可填写兼容 API 根地址。旧环境变量配置继续兼容。 | 必须 |
| REQ-AI-004 | AI 输出包含摘要、反方质询、下一步实验及每项引用的 `evidence_id`。 | 必须 |
| REQ-AI-005 | 不存在的证据引用、错误结论、非法结构、网络错误和超时均触发规则降级。 | 必须 |
| REQ-AI-006 | `ai_analysis_hash` 独立覆盖 evidence hash、模型、提示词版本和经校验的 AI 载荷。 | 必须 |
| REQ-AI-007 | 正式三种导出不包含 AI 解读；页面单独展示且标注不构成正式鉴证结论。 | 必须 |
| REQ-AI-008 | API Key 只从 `FACTORGUARD_LLM_API_KEY` 读取；不得进入页面输入控件、session state、请求正文、报告、日志或哈希。 | 必须 |
| REQ-AI-009 | 未知供应商、自定义供应商缺少 URL/模型、缺少 API Key 时必须安全降级。供应商或模型变化必须改变 `ai_analysis_hash`，不得改变正式 `report_hash`。 | 必须 |

| AC-AI-004 | REQ-AI-005 | 无配置或模型超时不阻断报告页，返回 `rule_fallback` 和原因。 | pytest + AppTest |

| AC-AI-007 | REQ-AI-003、009 | 七种供应商选项可解析为预设或自定义配置；显式页面参数覆盖环境值，环境值覆盖预设默认值。 | pytest + AppTest |

| AC-AI-009 | REQ-AI-009 | 未知供应商和不完整自定义配置返回 `rule_fallback`；供应商或模型变化改变 AI 哈希而不改变正式哈希。 | pytest |

## 风险与缓解

| 风险 | 影响 | 缓解措施 |
| --- | --- | --- |
| 模型幻觉 | 误导研究判断 | 强制结构、证据引用、结论一致性校验，失败即降级 |
| 模型或网络不可用 | 现场演示中断 | 按钮触发、短超时、规则降级，正式报告始终可用 |
| 密钥泄露 | 安全事故 | 仅环境变量读取，不记录、不回显、不持久化 |
| 厂商端点或模型下线 | 模型调用失败 | 预设仅提供默认值，模型 ID 可编辑，兼容根地址可由环境变量覆盖，失败统一降级 |
| AI 文本污染凭证 | 失去可复现性 | 独立 `ai_analysis_hash`，正式 `report_hash` 不含 AI |
